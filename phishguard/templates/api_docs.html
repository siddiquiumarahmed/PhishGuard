REST API

Version 1, served from /api/v1. JSON in, JSON out.

Sessions and CSRF

The API uses the same anonymous, cookie-based session as the web interface, so each client sees only its own scans. Requests that change data (POST, DELETE) must send the CSRF token from GET /api/v1/session in the X-CSRFToken header, and keep the session cookie.

Response format

{"ok": true,  "data": { ... }, "meta": { ... }}
{"ok": false, "error": {"code": "invalid_url.missing_scheme", "message": "...", "field": "url"}}

Endpoints

Method and pathPurpose
GET /api/v1/sessionStart a session; returns csrf_token.
POST /api/v1/scanScan a URL. Body {"url": "https://…"} (max {{ max_url_length }} characters). Returns 201 with the full report.
GET /api/v1/scansList your scans. Query: q, verdict, page, per_page (≤ 100).
GET /api/v1/scans/<id>One full report. Unknown or other sessions' IDs return 404.
DELETE /api/v1/scans/<id>Delete one of your scans.
GET /api/v1/healthLiveness and database check.
GET /api/v1/statusWhich detection components are available. Never returns keys.

Status codes

400 malformed request or failed CSRF check · 404 not found · 415 body is not JSON · 422 the URL was rejected by validation · 429 rate limit reached · 500 unexpected error (details only in the server log).

Example (PowerShell)

$base = "http://127.0.0.1:5000/api/v1"
$s = Invoke-RestMethod "$base/session" -SessionVariable pg
$body = @{ url = "https://paypal.com.account-verify.example.net/signin" } | ConvertTo-Json
$r = Invoke-RestMethod "$base/scan" -Method Post -WebSession $pg `
       -ContentType "application/json" -Headers @{ "X-CSRFToken" = $s.data.csrf_token } -Body $body
$r.data.verdict
$r.data.findings | Select-Object rule_id, severity, title

Example (Python)

import requests

s = requests.Session()
base = "http://127.0.0.1:5000/api/v1"
token = s.get(f"{base}/session").json()["data"]["csrf_token"]
r = s.post(f"{base}/scan", json={"url": "http://paypal.com@203.0.113.7/login"},
           headers={"X-CSRFToken": token})
print(r.status_code, r.json()["data"]["verdict"])
